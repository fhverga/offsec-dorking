## 🎯 Objetivo

O Offsec Recon foi desenvolvido para auxiliar profissionais de:

* Offensive Security
* Application Security
* Bug Bounty
* Red Team
* Attack Surface Management
* Security Research

na identificação rápida de exposições públicas através de mecanismos de busca, arquivos históricos e fontes OSINT.

---

## 🧠 Casos de Uso

### Attack Surface Mapping

Descobrir ativos públicos relacionados a um domínio.

### External Recon

Mapear aplicações, subdomínios e tecnologias expostas.

### Bug Bounty

Acelerar a fase inicial de reconhecimento.

### Security Assessments

Identificar potenciais exposições antes de um pentest.

---

## ⚠️ Aviso

Esta ferramenta utiliza exclusivamente fontes públicas e mecanismos de busca disponíveis publicamente.

O uso deve ocorrer apenas em ambientes autorizados e de acordo com as políticas da organização responsável pela avaliação.
